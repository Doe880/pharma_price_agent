# Мониторинг цен и маркетинговые исследования аптек

Проект автоматически проверяет карточки Apteka.ru и Здравсити для Москвы. Каталог содержит две формы Галавита, Amulapro и две версии Инстиго. Актуальные позиции перечислены в разделе «Каталог мониторинга». Точное наименование формы хранится в `catalog.json`. Бренды сравниваются по цене заданных упаковок.

## Запуск в Windows и PyCharm

Распакуйте архив и откройте папку в PyCharm. Выберите Python 3.10 или новее. В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe agent.py --no-ai
```

Откройте `data/prices_*.xlsx`. SQLite-файл `data/prices.sqlite3` хранит цены между запусками. В папке `example` находится актуальный пример расширенного отчёта по выбранным товарам. Новые срезы формируются командой `python agent.py`.

### OpenAI

Укажите переменную `OPENAI_API_KEY` в локальной конфигурации запуска PyCharm или в окружении PowerShell. Для ввода в PowerShell 5.1+ можно использовать:

```powershell
$env:OPENAI_API_KEY = (Get-Credential -UserName 'OpenAI' -Message 'Введите API-ключ в поле пароля').GetNetworkCredential().Password
.\.venv\Scripts\python.exe agent.py
```

По умолчанию используется `gpt-6-luna` через OpenAI Responses API. При необходимости задайте `OPENAI_MODEL` со значением другой модели, совместимой с Responses API и `reasoning.effort=none`. Эта переменная влияет на комментарий к ценам, аналитические листы используют Luna. Агент передаёт агрегаты по прямо проверенным аптечным карточкам. Текст модели попадает в комментарий Excel, а цены, наличие, медиана и изменения рассчитываются в Python. Без ключа или при ошибке API отчёт сохраняется с диагностикой.

Запускайте интеграцию с OpenAI в соответствии с [официальным списком поддерживаемых стран](https://developers.openai.com/api/docs/supported-countries). На момент пилота Россия отсутствовала в списке. Сбор и Excel можно запустить в режиме `--no-ai`.

## Ozon и Ютека

Автоматический сбор с Ozon и Ютеки требует доступного канала данных. В этой версии можно передать собственную выгрузку поставщика или заполнить шаблон `marketplace_feed.csv` по проверенным карточкам. Формат — CSV UTF-8 с разделителем запятой.

| Поле | Значение |
|---|---|
| source | `Ozon` или `Ютека` |
| sku | Ключ из `catalog.json` |
| city | `Москва` |
| seller | Точное имя продавца или аптеки |
| url | HTTPS-ссылка на карточку площадки |
| price_type | `public`, `from` или `card` |
| availability | `in_stock`, `out_of_stock` или `unknown` |
| observed_at | Фактическое время проверки в ISO 8601 с часовым поясом за текущую дату Москвы |
| price_rub | Цена упаковки. При `out_of_stock` оставить пустым |

```powershell
.\.venv\Scripts\python.exe agent.py --feed marketplace_feed.csv --no-ai
```

Проверяйте соответствие SKU исходной карточке при заполнении CSV. Агент валидирует поля и дату, а подтверждение продавца, цены и наличия в этом канале обеспечивает источник выгрузки. Импорт виден на листах «Проверки», «История» и «Изменения». Сводка минимума, медианы и максимума использует прямые публичные предложения с наличием. Сравнение за сутки строится между одинаковыми карточками одного продавца, канала и типа цены.

## Запуск по расписанию

Для постоянного сбора добавьте ежедневный запуск, например в 09:00 МСК, в Планировщик заданий Windows или в cron на сервере. Программа — полный путь к Python из виртуального окружения, аргумент — полный путь к `agent.py`. Задайте постоянный `--data-dir`, если данные нужно хранить вне папки проекта. Время в Excel указано по Москве.

Код завершения 2 означает, что часть или все прямые карточки завершились с ошибкой. Excel при этом сохраняется. Просматривайте лист «Проверки» и журнал запуска. В новой локации сначала проверьте, что сайты отдают нужный регион. Пилотные парсеры проверяют маркер Москвы в заголовке, а Здравсити использует общий регион «Москва и область». Географию за пределами Москвы потребуется проверить и добавить в адаптеры.

При расширении каталога создавайте новый ключ для новой комбинации бренда, дозировки, формы и размера упаковки. Идентификаторы источников и карточки проверяйте перед запуском. Для защищённых площадок используйте согласованный прайс-фид или разрешённую интеграцию.

## Маркетинговые исследования

Обычный запуск формирует расширенный Excel. Флаг `--prices-only` оставляет прежние четыре листа отчёта. Для первого запуска обновите зависимости из `requirements.txt`. История цен остаётся в `data/prices.sqlite3`. Для новых наблюдений и кеша разметки создаётся `data/research.sqlite3`.

| Листы | Что внутри |
|---|---|
| Отзывы по темам, Выборка отзывов | Бренд и точный SKU, количество отобранных и размеченных текстов, доля среди размеченных, до двух проверенных цитат и ссылки, вопрос для карточки или FAQ. Один отзыв может попасть в несколько тем. |
| Видимость, Позиции поиска, Потери видимости | Позиции, доля топ‑10 на проверенных запросах, охват из общего списка и сравнение только одинаковых запросов за две соседние даты. |
| Аудит карточек | Проверка дозировки, формы и размера упаковки по каталогу. Названия, ключевые слова описания и визуальный отпечаток основного фото сопоставляются между аптечными карточками. В отчёте указаны приоритет, значения, ссылки и действие для проверки. |
| Календарь промо, Частота промо | Акции, наборы и зачёркнутые цены, обнаруженные на карточках, срезы по датам, скидка при наличии двух сопоставимых цен, число уникальных промо, дней с промо и дней проверки за 30 дней. |
| Диагностика исследования | Покрытие источников, проблемы загрузки или обработки, статус Luna и определения показателей. |

### Сбор отзывов и работа Luna

Автоматически используются первые доступные отзывы с отдельных страниц Apteka.ru и данные карточек Здравсити. Лимит регулируется через `review_limit_per_card` в `research_config.json`. История копится между запусками, повторы с тем же SKU, аптекой, датой и текстом исключаются. Счётчик на витрине может включать больше отзывов, чем доступно сборщику. Выборка включает разные даты, которые видны на листе «Выборка отзывов».

Для разметки используется `gpt-6-luna`. Задайте `OPENAI_API_KEY` и запустите `agent.py` без `--no-ai`. В модель попадают текст отзыва, поисковая фраза или текст промомеханики и служебный номер. Метаданные об авторе не собираются, телефонные номера российского формата, ссылки и email маскируются. Цитата принимается только при дословном совпадении с обработанным текстом. Разметка кешируется. Параметр `max_ai_new_reviews` ограничивает число новых отзывов для обработки за запуск.

Excel формируется и без ключа. Новые отзывы получают статус «Ожидает разметки», запросы помечаются «Не размечено», а промо показывают механику по признакам сайта. Цены, позиции и аудит рассчитываются на стороне Python. Если ключ задан, цитаты отражают высказывания авторов и служат материалом для проверки вопросов покупателей. Сравнение описаний и фотографий — редакционный аудит карточек.

### Видимость в поиске аптек

`research_config.json` задаёт фиксированные города, поисковые фразы, целевые SKU и порог снижения доли. В пилоте установлен один город — Москва. Для остальных городов сначала добавьте город в конфигурацию и подготовьте соответствующие срезы, с фактической региональной выдачей. Для проверки цен город по-прежнему задаётся в каталоге.

В `robots.txt` Apteka.ru и Здравсити закрывают автоматический обход поисковой выдачи. Проект обрабатывает два согласованных входа:

- **CSV с позициями.** Возьмите разрешённую выгрузку или вручную заполните шаблон `visibility_feed.csv`. Запишите одну строку для каждого целевого SKU в срезе. `source` — `Apteka.ru` или `Здравсити`; `city` и `query` из конфига; `observed_at` содержит дату и часовой пояс; `result_url` — URL результатов. `position` — позиция товарной карточки, начиная с 1; `depth` — сколько позиций проверили. Для `not_found` оставьте позицию пустой, для `error` укажите глубину 0. Если товар найден, укажите `found`. Пример команды: `python agent.py --visibility-feed visibility_feed.csv --no-ai`.
- **Сохранённый HTML поисковой страницы.** Откройте сайт вручную, выставьте нужный город, выполните запрос и сохраните страницу в HTML UTF‑8. В `search_snapshots.csv` внесите `source,city,query,observed_at,result_url,html_path`. `html_path` может быть путём относительно CSV. Парсер проверяет признаки запроса и города, берёт порядок уникальных товарных карточек из списка и записывает позиции целевых SKU. Если разметка страницы не распознаётся, используйте CSV. Пример команды: `python agent.py --search-snapshots search_snapshots.csv --no-ai`.

Выберите для каждого среза один способ импорта. Импорт принимает срезы за текущую дату Москвы. Глубина меньше десяти засчитывается в долю топ‑10, если целевой SKU действительно найден. Если SKU не найден, нужны просмотренные десять позиций. Ошибки и пропуски видны в подробном листе. Для сравнения по площадкам используйте одинаковые запросы, время и одинаковый подход к учёту промопозиций.

### Как читать календарь промо

«Впервые замечена» и «Последний раз» — даты фактических наблюдений. Скидка рассчитывается как разница между зачёркнутой и текущей ценой, делённая на зачёркнутую цену. Для комплектов используется цена всего комплекта. Если исходная цена отсутствует, скидка остаётся пустой. Отчёт охватывает промо, показанные на проверяемых карточках, включая блоки выгодных наборов. Частота отражает уникальные обнаруженные промопредложения и количество дней, в которые они встречались.

## Дашборд Streamlit

В терминале PyCharm или PowerShell из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dashboard.txt
.\.venv\Scripts\python.exe -m streamlit run dashboard.py --server.address localhost
```

Также можно открыть `start_dashboard.bat` после установки зависимостей. Интерфейс доступен на [http://localhost:8501](http://localhost:8501). Графики построены по готовым Excel-отчётам. Дашборд открывает последний отчёт из `data`, позволяет выбрать более ранний и скачать его. Если отчётов ещё нет, открывается пример из папки `example`. Для нестандартного `--data-dir` задайте ту же папку переменной окружения `PHARMA_DATA_DIR` перед запуском Streamlit.

Чтобы обновить данные, запустите `agent.py` обычной командой или по вашему расписанию. Затем обновите список отчётов на боковой панели дашборда и выберите полученный файл. Сбор данных выполняет агент. Дашборд открывает сохранённые результаты. Ключ OpenAI нужен агенту при разметке, а графики используют имеющиеся данные. Вкладка «Видимость» появится с заполненными показателями после импорта поисковых срезов. Фильтр города относится к ценам, видимости и промо. Отзывы и аудит относятся к карточкам товара.

## ИИ сводка в дашборде

На вкладке «ИИ-сводка» нажмите «Сформировать ИИ-сводку». Luna получает агрегированные показатели текущего отчёта и выбранных фильтров по всем пяти разделам. Тексты отзывов и цитаты, имена авторов, ссылки и API-ключ в аналитические данные не входят. Текст сводки можно скачать в Markdown.

Задайте ключ через поле «API-ключ» в боковой панели или скопируйте `.env.example` в `.env` рядом с `dashboard.py` и заполните `OPENAI_API_KEY`. После изменения файла перезапустите дашборд. Поле ввода скрывает символы. Ключ из поля используется в текущем окне, а сохранённые сводки содержат только ответ модели и время его получения.

Сводка запрашивается по кнопке. Результат сохраняется в `data/dashboard_summaries.sqlite3` и повторно открывается для тех же показателей, отчёта и фильтров. При выборе другого отчёта или набора SKU дашборд показывает соответствующий результат либо предлагает создать новый. В примере с неразмеченными отзывами и без поисковых срезов модель получает информацию об этих пробелах.

## Каталог мониторинга

| SKU | Товар | Упаковка | Прямые источники |
|---|---|---|---|
| galavit-100-10 | Галавит 100 мг, суппозитории ректальные | 10 шт. | Apteka.ru, Здравсити |
| galavit-powder-100-5 | Галавит 100 мг, порошок для приготовления раствора во флаконах | 5 шт. | Apteka.ru, Здравсити |
| amulapro-powder-5g-30 | Амула Про / Amulapro, порошок в саше по 5 г | 30 шт. | Apteka.ru |
| instigo-men-395-30 | Инстиго для него, капсулы массой 395 мг | 30 шт. | Apteka.ru, Здравсити |
| instigo-women-675-30 | Инстиго для нее, капсулы массой 675 мг | 30 шт. | Apteka.ru, Здравсити |

Масса саше и капсул указывается для идентификации товара и сопоставления карточек. В дашборде форма выпуска включена в подпись товара. Обе версии Инстиго отслеживаются отдельно.

Лонгидаза и Суперлимф исключены из текущего каталога и поисковых запросов. В новых отчётах и текущих фильтрах дашборда отображаются товары из каталога. Прежняя SQLite-база поддерживается, история в отчёт выбирается только для актуальных SKU.

Проверка наличия выполняется при каждом сборе. При отсутствии товара цена не используется в сравнении публичных предложений.
